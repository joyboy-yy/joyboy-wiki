# AI Agent 项目接入检查清单

## 项目事实

- [ ] 已识别技术栈的权威依赖清单和锁文件
- [ ] 已梳理模块边界和依赖方向
- [ ] 已确认启动端口、context path 和环境配置
- [ ] 已确认数据库类型、方言、schema 和迁移规则
- [ ] 已确认 API 文档和前端契约位置

## 入口规则

- [ ] `AGENTS.md` / `CLAUDE.md` 控制在必要上下文范围
- [ ] 两个客户端入口语义一致
- [ ] 中文镜像章节对齐
- [ ] 已建立按变更类型读取的路由表
- [ ] 未在团队入口复制完整命令表和工具列表

## 执行能力

- [ ] 构建、测试、启动、打包有统一项目命令
- [ ] 命令能够输出准确退出码和日志
- [ ] 聚焦测试、模块测试、集成测试语义明确
- [ ] 前端构建与浏览器测试分开
- [ ] 测试跳过和零测试不会被误报为通过

## 个人与团队隔离

- [ ] MCP 密钥、主机和本机路径不在团队文档
- [ ] 个人 Skills 和配置已按策略忽略
- [ ] 测试文件提交策略明确
- [ ] 提交前有 staged 文件检查

## Skill 与 MCP

- [ ] 重复判断流程已识别为 Skill 候选
- [ ] Skill description 覆盖真实中英文触发词
- [ ] 每个可选工具都有使用门禁和回退路径
- [ ] MCP 默认只读，写操作需要审批
- [ ] 已用不同任务场景验证 Skill 不会过度触发

## 完成证据

- [ ] 明确有无 CI 门禁
- [ ] 最终报告格式包含命令、结果、跳过和风险
- [ ] 文档镜像、链接和命令存在性可本地检查
- [ ] 项目知识和个人方法论有明确沉淀位置

# 全局 MCP 能力索引

本页只记录跨项目可用且在当前运行时公开的 MCP。项目配置的 OpenAPI、数据库和业务系统 MCP 留在项目架构中。

## Chrome DevTools

| 能力 | 典型场景 |
|---|---|
| 页面与标签页 | 新建、选择、导航、刷新、关闭页面 |
| 页面理解 | Accessibility snapshot、截图、元素定位 |
| 页面交互 | 点击、输入、表单、上传、键盘、拖拽、悬停 |
| 运行时诊断 | Console 消息、Network 请求与响应、浏览器对话框 |
| 环境模拟 | 视口、移动端、触摸、网络、CPU、地理位置、颜色模式 |
| 性能 | Performance trace、Core Web Vitals insight、heap snapshot |
| 质量 | Lighthouse accessibility、SEO、best practices |

触发条件：页面白屏、交互异常、登录态问题、Console 错误、失败请求、性能或浏览器环境差异。

停止条件：目标页面状态、具体 Console 信息或具体请求已经支持下一步决策。不要无目标抓取全部日志和请求。

## Memory 知识图谱

| 能力 | 典型场景 |
|---|---|
| 实体 | 创建、查询、打开和删除实体 |
| 观察 | 为实体增加或删除事实观察 |
| 关系 | 创建或删除实体之间的主动关系 |
| 检索 | 搜索节点或读取完整知识图谱资源 |

适合保存结构化、稳定、可关联的实体事实和关系。不适合替代 Obsidian 中的长文设计、项目日志、操作记录和含敏感信息的配置。

## 全局与项目 MCP

| 层级 | 示例 | 归属 |
|---|---|---|
| 全局 | Chrome DevTools、Memory | 个人工具能力索引 |
| 项目 | `house-openapi`、`dm8-server` | 项目工程架构与项目配置 |
| 临时 | 某次调试接入的服务 | 任务记录，稳定后再决定归属 |

## 安全与门禁

- 默认使用只读能力；浏览器提交、数据库 DML、发布和删除属于更高风险操作。
- MCP 存在不代表应该调用；证据缺口必须与工具能力直接匹配。
- 不记录 MCP Token、账号、密码、私有主机或浏览器 profile。
- 配置来源受权限保护时，不绕过权限枚举隐藏配置。
- MCP 不可用时报告缺失证据，不用无关工具伪造等价覆盖。
